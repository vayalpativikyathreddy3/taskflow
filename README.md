Project Title: TaskFlow

Project Description:
TaskFlow is a web-based task management and productivity application developed using HTML, CSS, and JavaScript. The main objective of this project is to help users organize their daily work, manage projects, and improve productivity through an easy-to-use interface. The application combines task management with modern productivity tools such as a Kanban board, calendar, Pomodoro timer, analytics dashboard, and AI-powered suggestions. Since it is built using vanilla JavaScript, it does not require any frameworks or build tools, making it lightweight, simple to understand, and easy to run.

Features:
Create, edit, delete, and organize tasks.
Assign priorities, categories, tags, due dates, and recurring schedules.
Add subtasks and monitor their completion progress.
Track the time spent on individual tasks with start, pause, and manual adjustment options.
Write formatted notes using a simple rich text editor.
Maintain a complete history of task activities.
Create and manage multiple projects with custom colors and icons.
Organize tasks visually using a drag-and-drop Kanban board.
View tasks in a monthly calendar and quickly create tasks for selected dates.
Analyze productivity using charts and reports.
Improve focus with a built-in Pomodoro timer.
Receive browser notifications for upcoming and overdue tasks.
Get task recommendations and workload summaries from a built-in rule-based AI assistant.
Optionally back up data to Google Drive using a Gmail account.
Import and export project data in JSON and PDF formats.
Switch between light and dark themes.
Use the application comfortably on desktops, tablets, and mobile devices.
Access important features quickly through keyboard shortcuts and accessibility support.

Technologies Used:
HTML
CSS
JavaScript

Project Structure:
The project is divided into separate HTML, CSS, and JavaScript files to keep the code organized and easy to maintain.
index.html serves as the landing page and introduces the application.
about.html provides information about the project and its objectives.
app.html contains the complete task management system.
The css folder stores separate style files for different sections such as dashboard, tasks, projects, analytics, Kanban board, and settings.
The js folder contains individual JavaScript files responsible for handling features such as task management, projects, calendar, analytics, Pomodoro timer, notifications, cloud synchronization, AI assistant, import/export, keyboard shortcuts, and application initialization.

How to Run the Project:
Clone the repository to your computer.
Open the following address in your web browser:
https://taskflow-kappa-pink.vercel.app/
You can also use any static file server such as VS Code Live Server if preferred.

TaskFlow is a complete productivity and task management application that combines project organization, time management, analytics, and planning into a single platform.
